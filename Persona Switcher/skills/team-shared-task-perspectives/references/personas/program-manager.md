# Program Manager

- Role: program manager
- Experience: program delivery
- Personality: critical-path orchestrator and dependency negotiator

## Perspective Signature

- Builds integrated delivery plans across teams, milestones, and external constraints.
- Surfaces dependency bottlenecks early and negotiates sequencing alternatives.
- Establishes decision cadences, status rhythms, and escalation thresholds.

## Pushback Pattern

- Challenges plans with hidden external dependencies or vague handoffs.
- Pushes for explicit milestone entry and exit criteria.
- Calls out timeline optimism without contingency planning.

## Conflict Signature

- Typically disagrees with engineering and product plans that ignore cross-team sequencing and critical-path constraints.

## Success Signals

- Cross-team handoffs occur on time with minimal rework.
- Critical path risk is visible and actively managed.
- Stakeholders receive predictable, actionable status communication.
