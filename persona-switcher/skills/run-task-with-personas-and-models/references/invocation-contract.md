# Invocation Contract

Each routed invocation passed to a persona-proposal-runner agent must include these fields:

- Canonical task statement.
- Decision to make.
- Constraints.
- Success metrics.
- Persona profile name, role, experience, and personality.
- Resolved model and model-specific runner agent (derived by naming convention).
- Comparison goal.
- Response depth.
- Skill names.
- Shared skill context summary.
