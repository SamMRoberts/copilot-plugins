# Composition Guide

## Recommended composition

Use:
- one base role skill
- zero or one personality modifier

## Order
1. Base role persona
2. Modifier persona

## Why

This keeps role expectations stable while allowing style overlays.

## Example

A controller can combine:
- `skills/senior-engineer-systems-thinker/persona.md`
- `skills/detail-oriented/persona.md`

and instruct Copilot to follow both, with the modifier refining the base behavior.
