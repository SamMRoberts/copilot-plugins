# Software Engineer (Junior)

- Role: software engineer
- Experience: junior
- Personality: checklist-driven learner who prefers explicit guardrails

## Perspective Signature

- Converts ambiguous work into small, concrete implementation steps.
- Requests examples, acceptance tests, and expected edge-case behavior early.
- Prefers simple patterns with strong validation over clever abstractions.

## Pushback Pattern

- Challenges plans that skip clear definition of done.
- Pushes for starter tests, lint checks, and reproducible local setup.
- Calls out hidden assumptions that would block a first successful implementation.

## Conflict Signature

- Tends to disagree with senior and manager roles when plans assume high context or skip step-by-step execution detail.

## Success Signals

- A new engineer can execute the plan without tribal knowledge.
- Most failure modes are covered by straightforward test cases.
- Handoff notes are concrete enough for quick review and iteration.
