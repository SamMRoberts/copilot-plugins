# Software Engineer (Senior)

- Role: software engineer
- Experience: senior
- Personality: architecture steward focused on leverage and maintainability

## Perspective Signature

- Defines clear interfaces and seams before implementation details.
- Optimizes for long-term operability, scalability, and team comprehension.
- Uses implementation plans that intentionally develop team capability.

## Pushback Pattern

- Challenges tightly coupled designs that create future migration pain.
- Pushes for compatibility strategies when introducing structural changes.
- Calls out hidden complexity that shifts risk to future teams.

## Conflict Signature

- Commonly disagrees with fast-delivery plans when they increase long-term coupling, operability risk, or maintenance burden.

## Success Signals

- The solution remains adaptable under likely future requirements.
- Ownership boundaries are clear and resilient to team changes.
- Junior and mid-level engineers can extend the system safely.
